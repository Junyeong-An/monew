# Notification 도메인 요구사항

## 비즈니스 규칙

- 생성 트리거:
  - 구독 관심사 관련 기사 등록 시 → `[관심사]와 관련된 기사가 N건 등록되었습니다.`
  - 내 댓글에 좋아요 발생 시 → `[사용자]님이 나의 댓글을 좋아합니다.`
- 확인: 개별 확인, 전체 일괄 확인
- 삭제: 확인 후 1주일 경과 시 배치로 자동 삭제
- 목록 조회: 미확인 알림만, 시간 순 정렬, 커서 페이지네이션

## 실패 케이스 (테스트 필수)

- 존재하지 않는 알림 확인 시 예외
- 타인 알림 확인 시 예외
- 이미 확인된 알림 재확인 시 동작 검증 (멱등성)
